# Hello Model notebooks

Runnable Jupyter notebooks for [Hello Model](https://sayhellomodel.com), a free planner and guide for machine learning projects. The “Run in Colab” buttons on the site open these notebooks in Google Colab.

- `guides/`: one notebook per [step-by-step guide](https://sayhellomodel.com/guides/), with every code block in order and its explanations. The sales forecast, recommendations, defect photos, machine failures and delivery times guides generate their own sample data, so they run with nothing to upload.
- `models/`: one notebook per [model type](https://sayhellomodel.com/models/), with a quick start and code to train your own model.

To open one in Colab, use its button on the site, or go to `https://colab.research.google.com/github/hitman449/hello-model-notebooks/blob/main/` followed by the file’s path, for example `guides/spam-filter.ipynb`.

Where the code reads a file (such as `orders.csv`), upload yours with the Files panel on the left in Colab, or change the file name. Run the cells from the top, one at a time.

These notebooks are generated from the site’s content and updated automatically when it changes, so edits made here are overwritten. To report a problem, use the [contact page](https://sayhellomodel.com/contact/).
